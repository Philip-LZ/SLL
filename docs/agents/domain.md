# Domain docs

## Layout and reading rules

This repo uses a single-context layout:

- CONTEXT.md at the repo root contains domain terms.
- docs/adr/ contains architectural decision records.

Before exploring, read CONTEXT.md and ADRs relevant to the area.
If they do not exist, proceed silently. Domain modeling creates
them when terms or decisions are resolved.

## Vocabulary

Use terms defined in CONTEXT.md when naming domain concepts.
Reconsider unfamiliar terms; note genuine glossary gaps for domain modeling.

## Decisions

Explicitly flag proposals that contradict an existing ADR,
identifying the ADR and explaining why it should be reconsidered.
